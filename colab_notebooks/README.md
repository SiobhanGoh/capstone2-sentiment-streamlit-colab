# Training notebooks

- `CP2_malaybert_training.ipynb`: corrected shared-split baseline/mBERT workflow.
- `CP3_candidate_models.ipynb`: fine-tunes three Malaysian and tweet-trained base models under the same frozen split and picks a winner by validation macro-F1 before any test score is computed. Generated by `training/make_candidates_notebook.py`; the logic lives in `training/candidates.py`.
- `CP1_training.ipynb`: historical undergraduate baseline work; not the corrected comparison.
- `archive/CP2_original_exploration.ipynb`: original exploratory code, with execution disabled and stale outputs removed. Historical rendered results remain in Git history. Three cells damaged in an earlier edit were restored from the original Colab notebook in November 2026.

See the root README and `training/` for the reproducible commands. The dataset stays local; public results contain aggregate metrics only.
